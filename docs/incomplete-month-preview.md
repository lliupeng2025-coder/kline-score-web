# 未完成月K展示与黄金分割（2026-10-25）

用户授权：正式版月线尾部展示当前未完成月，由当前月已完成周合成；月初跨月周使用文华日K精确裁剪。黄金分割为38.2%、50%、61.8%，标签在各线可见左端。

## 口径

- `monthly_bars` 仍仅存完整原生月线。未完成月K只在前端临时生成，`is_incomplete=true`，不写周/月行情表，不进入反转榜或右侧完整月方向栏。
- 上海时间以该交易周最后交易日15:30为完成点。10月15日仅用10月8—9日；10月24/25日用10月8—23日。首开、最高、最低、末收、vol加总。缺首周/中间周、重复周、无上一完整月基准时拒绝合成并提示。
- 第一周若跨月，不能将上月高低点/量混入；读取文华原生day缓存，只接受所需日期的官方收盘记录（普通07:00 UTC、四国债07:15 UTC），完整覆盖才生成边界片段。日K不足时该品种不生成未完成月K，不补0、不使用整根跨月周代替。
- 从上一完整月复制已有力量线，未完成月low <= 向上力量原月low或high >= 向下力量原月high时剔除；不新增、恢复或重组力量线，本根分为null。剩余总分为存量带方向求和，零分时取最近存量力量方向，无存量为none。不给未完成月产生新反转标记。
- 趋势线和计算起点沿用完整月并明确标注；不重新推导趋势阶段。未完成月BOLL/MV留空；历史完整月份的快照不改变。点击未完成K得到高低点破坏快照；双击回最新。

## 正式更新新增步骤

辅助构建器 `D:/ywl/build_month_preview_context.py` 读取87品种映射、正式交易日历与文华day缓存，生成 `formal-month-preview/v1` 上下文。独立资产名固定 `formal-month-preview-context.json`，通过既有 `put_web_asset` RPC发布，前端匿名只读 `web_assets` 获取；不改权限或写月表。

在完成源行情核验后、正式页面发布前执行（解释器先按实际环境核验）：

```powershell
& '<可用Python路径>' 'D:/ywl/build_month_preview_context.py' --output 'D:/ywl/outputs/<本次目录>/month_preview_context.json' --push
```

输出证据不覆盖；已有文件须另取新名字。缺省当前上海月份，`--mapping`、`--holidays`、`--data-root`可显式适配，私密配置沿用`str/web_snapshot_config.json`。跨月所需日K未齐时汇报`boundary_unavailable`及品种；前端仅对缺源品种提示。现行节假日日历必须独立核对覆盖，年份检查本身不证明全年完整。新月份需重新构建上下文；长期开着的网页在跨月更新后应刷新。
